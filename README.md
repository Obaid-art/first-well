# First Well

A short game for the first chapter of a petroleum production engineering course. You are given one oil well. You open it, measure it, and work out the rule that sets its rate.

This is an early demo of Act 1, shared for comments. It takes about ten minutes and works best on a laptop.

Play it: https://obaid-art.github.io/first-well/

The well's behaviour is calculated from standard textbook relations (Economides et al., *Petroleum Production Systems*): the productivity index, the Hagedorn and Brown pressure traverse, and the Gilbert choke correlation.

Rock textures are from Poly Haven (CC0); see `hero/tex/CREDITS.md`. Charts use Plotly; the 3D view uses three.js; equations use KaTeX.
