# Texture credits

All texture sets in this folder are from Poly Haven (https://polyhaven.com), released under CC0 (public domain).
Each set is used at 1k JPG: colour (`_diff`), OpenGL normal (`_nor`) and AO / roughness / metal (`_arm`). Downloaded 2026-11-19.

| Set | Used for | Page |
|---|---|---|
| worn_rock_natural_01 | the reservoir sandstone (darkened and desaturated as oil-stained) | https://polyhaven.com/a/worn_rock_natural_01 |
| dark_rock_02 | cap rock, the dark shale seal | https://polyhaven.com/a/dark_rock_02 |
| marble_cliff_04 | the limestone bed (rotated so its fabric lies flat) | https://polyhaven.com/a/marble_cliff_04 |
| cliff_side | the red beds | https://polyhaven.com/a/cliff_side |
| seaside_rock | the grey-green shale bed and the shale beneath the reservoir | https://polyhaven.com/a/seaside_rock |
| rock_face_03 | the weathered rock under the sand | https://polyhaven.com/a/rock_face_03 |
| aerial_beach_01 | the desert surface (tinted to desert sand) | https://polyhaven.com/a/aerial_beach_01 |

The lighting environment (royal_esplanade_1k.hdr) is loaded at run time from the three.js examples on jsDelivr; it is also a Poly Haven HDRI, CC0.
